Expand description

The controls’ scale and the window size, carried between frames.

Fields§

§scale: UiScale§toolbar: f32

Heights in points of the toolbar, one of its buttons, and all the panels around the display, as last laid out.

§button: f32§panels: f32§settled: bool

Whether the zoom factor is where scale wants it.

§resize: bool

A display was shown: size the window to it if allowed.

§auto_size: bool

Size the window to every display shown, not only the first; the toolbar’s Auto-size toggle.

§first: bool

The window has not been sized yet.

§hold: bool

Keep the window’s size for the next display shown: a layout gave it.

§fit: bool

Size the window to the display next frame, Auto-size or not.
