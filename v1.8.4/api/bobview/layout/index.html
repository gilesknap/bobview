Saved window layouts: which displays are open, in which windows, where.

A layout is a JSON file in $XDG_CONFIG_HOME/bobview/layouts (by default ~/.config/bobview/layouts), named after the layout; default.json is restored at startup. Positions and sizes are in desktop points (egui’s points times its zoom factor), so they don’t depend on the controls’ scale.
