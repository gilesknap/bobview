Environment variables

EPICS

bobview, bobview-probe and bobview-server read the standard EPICS client variables:

variablemeaning
EPICS_CA_ADDR_LISThosts or broadcast addresses to search for CA PVs
EPICS_CA_AUTO_ADDR_LISTNO to search only EPICS_CA_ADDR_LIST
EPICS_CA_NAME_SERVERShost:port of CA name servers (gateways) reached over TCP
EPICS_PVA_ADDR_LISThosts or broadcast addresses to search for PVA PVs
EPICS_PVA_AUTO_ADDR_LISTNO to search only EPICS_PVA_ADDR_LIST
EPICS_PVA_NAME_SERVERShost:port of PVA servers reached over TCP

bobview-testioc reads the server variables: EPICS_CA_SERVER_PORT, EPICS_CAS_*, EPICS_PVAS_SERVER_PORT / EPICS_PVA_SERVER_PORT (TCP, default 5075) and EPICS_PVAS_BROADCAST_PORT (UDP search, default 5076).

bobview

variablemeaning
BOBVIEW_LOGlog level, e.g. debug for more output
BOBVIEW_UI_SCALEas --ui-scale
XDG_CONFIG_HOMElayouts are in $XDG_CONFIG_HOME/bobview/layouts (default ~/.config/bobview/layouts)
WAYLAND_DISPLAYset it empty to run under XWayland, so layouts keep window positions

Displays opened from files also fall back to environment variables for macros they don't define; see Macros, rules and PV types.

bobview-server

variablemeaning
BOBVIEW_WRITE_TOKENthe write token for --write; an empty value counts as unset

Tests

The interop tests in crates/pv/tests/interop.rs are skipped unless these name PVs to read:

variablemeaning
BOBVIEW_INTEROP_CA_PVa PV served by the IOC over Channel Access
BOBVIEW_INTEROP_PVA_PVa PV served by the IOC over PV Access (PVXS)
BOBVIEW_INTEROP_GW_PVa PV reached through ca-gateway (CA)
BOBVIEW_INTEROP_WRITE_PVoptional writable numeric PV; set to 7 and read back
BOBVIEW_INTEROP_REQUIRE1 to fail instead of skipping when a variable is missing
