pub fn svg_cost(doc: &Document<'_>) -> Cost
Expand description

The cost of doc. Its depth is the deepest element nesting with the references usvg follows (url(#id) in an attribute, a style or a style sheet, and an href to #id) counted as REF_LEVELS levels each: how deep usvg recurses to parse it. Its work counts each element once for each time usvg may convert it: usvg converts a marker at every vertex it marks, and a pattern, mask, clip path or filter for each element using it, so references from references multiply. Found without recursion, in time linear in the size of doc and its style sheets.

An element’s references count from the deepest element below it, as that may be where an inherited fill or marker is resolved, or where the content of a <use> (which inherits from the <use>) resolves others. Following one into an element also leads to the references it inherits from its own ancestors, as usvg converts patterns, markers, masks, clip paths and the elements a filter image names where they are.
