The navigator: a tree, beside the main window’s display, of the displays it links to, the displays those link to, and so on.

A display’s links are its widgets’ Open display actions, and the command actions that may run a launcher script, in groups, tabs and embedded displays too. They are read from the display file without building the display, so no PVs are connected, on threads, when the display’s node is first shown: a branch is read as its parent is opened, one level ahead, which shows which nodes have links of their own. A command’s display is found by running its script, so only when its node is opened or clicked. A display that links back to one above it is shown, marked ↻, but not opened again.
