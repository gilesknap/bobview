bobview: a lean viewer for Phoebus .bob displays (and CS-Studio BOY .opi).

Modules§

app 🔒
The application window: navigation bar, display area and status line.
axis 🔒
Numeric scales shared by plots, meters and the image colour bar: where the ticks go and how their labels read.
chrome 🔒
Sizing of bobview’s own controls (toolbar, status line, menus) and of the native window.
colormaps 🔒
Colour maps for the image widget, from the Phoebus predefined maps (viridis and magma are the matplotlib CC0 tables).
fetch 🔒
Reading displays from files or over HTTP(S).
format 🔒
Values as text and back, as Phoebus’s FormatOptionHandler does it for a widget’s format, precision and show_units.
group_link 🔒
Widgets that show the group a vacuum space’s link field names, as the DLS get_pv_name.py script makes them (see bob::GroupLink).
icons 🔒
The toolbars’ icons, drawn as strokes so they look the same on every platform (the fonts’ symbols vary, and some are emoji).
image 🔒
The image widget: a PVA NTNDArray (or a CA waveform shaped by data_width x data_height) drawn through a colour map, with a colour bar and, when show_toolbar is set, the Phoebus zoom/pan/crosshair toolbar.
launch 🔒
DLS CS-Studio launcher scripts, run by .opi command actions.
layout 🔒
Saved window layouts: which displays are open, in which windows, where.
meter 🔒
The linear meter: a scale with coloured warning regions and a needle at the value, after Phoebus’ RTLinearMeter; and the round meter, a dial.
plot 🔒
The XY plot widget: array PVs drawn against their index or another array, with axes, grid and legend laid out as in Phoebus. A BOY XY graph’s concatenating trace plots its PVs’ last updates instead.
polygon 🔒
Filling polygons that may be concave (L shapes, arrows, synoptic outlines), which egui’s convex_polygon fills wrongly.
pvmenu 🔒
The context menu on widgets with a PV (right-click, or long-press on a touch screen) and the PV details window it can open.
rules 🔒
Phoebus rules: expressions over a widget’s rule PVs that override one property.
screen 🔒
A loaded display: widgets with resolved positions, macros and PVs.
selection 🔒
The primary selection: the text a middle-click pastes on X11 and Wayland, which a middle-click on a widget sets to its PV name, as in EDM and MEDM, and a middle-click on a trend reads to add the PVs it names. egui sets only the clipboard, and reads neither.
snapshot 🔒
Render a display to a PNG without a window: egui runs headless and its triangles are rasterised in software. Used for checking layouts in CI and on machines without a display.
stripchart 🔒
The strip chart widget: its PVs plotted against time, live. Each PV keeps the samples it has had since the display opened; there is no archived history. (Trend windows are archiveview plots: see trend.)
style 🔒
Colours, fonts and coordinates shared by the widget painters.
svg 🔒
Parsing SVGs, and the images they embed, without trusting them.
symbol 🔒
Symbol and picture widgets: SVG or PNG images from files or URLs.
tree 🔒
The navigator: a tree, beside the main window’s display, of the displays it links to, the displays those link to, and so on.
trend 🔒
Trend windows: PVs plotted against time, archived history and live values, by archiveview’s [Plot]. Opened from a widget’s context menu, a BOY “Graph” button, or a Data Browser or StripTool launcher. The plot fetches history from the Archiver Appliance bobview was given (--archiver), or is live only without one.
view 🔒
One display and its navigation: what a window shows.
widgets 🔒
Painting and interaction for each widget type.
