pub fn reshape(&mut self, before: [f64; 4], after: [f64; 4])

Move and size the widget from geometry before (x, y, width, height as its properties gave them) to after, as a rule does; its children move with it. Changes, not the values, are applied, so a size set from the content (an embedded display’s resize mode 2) or the parent’s offset is kept.
