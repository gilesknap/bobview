Expand description

expand_for, with the properties being expanded and their values so far in state. A widget property may name others, as BOY’s rule PV $(pv_name) does with $(name):STA and the name $(prefix)$(cell)S-VA-PIRG-01; one that names itself, directly or not, or anything unknown, too long or naming others too deeply is left as written. Each is expanded once, so properties that name others several times don’t take exponential time.
