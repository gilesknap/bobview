Module stripchart 

Source
Expand description

The strip chart widget: its PVs plotted against time, live. Each PV keeps the samples it has had since the display opened; there is no archived history. (Trend windows are archiveview plots: see trend.)

Samples
One PV’s samples, in time order: (seconds since 1970, value), a NaN value marking where it disconnected.
Series
A PV being trended: a sample on each update, at the time it arrived.
Thinned 🔒
One PV’s samples thinned for drawing: in each column of time dt wide (a pixel or less), the first, lowest, highest and last sample, which draw the same as all of them. Kept from frame to frame, taking in only the samples added since, so a day of fast samples is not copied out and stepped through on every frame.

Samples kept per PV: at most this many (1.6 MB), and none older than a day.
MIN_SCROLL_REPAINT 🔒
The quickest a plot redraws for time moving on alone: a display redraws all of itself each frame, so a strip chart must not keep it at the 10 frames a second PV updates are held to.
TIME_STEPS 🔒
Steps for the time axis, in seconds: whole seconds, minutes and hours.
