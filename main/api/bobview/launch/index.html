DLS CS-Studio launcher scripts, run by .opi command actions.

DLS BOY screens open many others (such as the storage ring cell screens) with a command like ./srCellVacuum 04: a shell script that works out a display and its macros and ends with runcss.sh DISPLAY -m MACROS, which starts CS-Studio. bobview runs a copy of such a script next to a stand-in runcss.sh that only records its arguments, and opens that display itself. Other commands are not run.

Nothing is run for a display fetched over HTTP, nor any script that does not lie beside or under the display or in a linked folder of its Eclipse project (after macros and .. are resolved), nor one that other users may change (writable by others, or in a folder that is).
