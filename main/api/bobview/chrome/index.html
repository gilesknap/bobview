Sizing of bobview’s own controls (toolbar, status line, menus) and of the native window.

egui sizes everything in points and multiplies by the desktop’s scale factor, which on a phone (2.5-3) makes the controls take a large share of a small screen. The display itself is unaffected: it is fitted to the space left over. So the controls get their own scale, set through egui’s zoom factor: by default chosen from the screen size in physical pixels, or fixed with --ui-scale / BOBVIEW_UI_SCALE.
