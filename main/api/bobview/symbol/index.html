Module symbol 

Source
Expand description

Symbol and picture widgets: SVG or PNG images from files or URLs.

A symbol shows one of its symbols, picked by its PV’s value, and may run its actions when clicked; a picture shows one file. A symbol translated from a DLS EDM symbol in an .opi has one image, a horizontal strip of frames sub_image_width wide, and shows the frame its rules pick with image_index. Images load on a thread and are kept, decoded, for every widget that names them; each widget keeps its own texture at the size it is drawn.
