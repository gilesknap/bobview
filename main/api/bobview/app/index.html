Structs§

App
bobview as eframe runs it: the application behind one lock, so that each display and trend window is drawn in a pass of its own (a deferred viewport), redrawn only for its own input and its own PVs, not in the main window’s pass. eframe draws the windows one after another on one thread, so their passes never wait for each other.

beside 🔒
Where a window size inside (in desktop points) goes beside the window at origin, clear of it and of the pinned windows (the one pinned last first). The places tried are beside the window pinned last, so a row of small windows grows beside a big one, then beside origin, then beside each other pinned window: to its right (top edges level), below it (left edges level), to its left and above it, each slid along that side to stay on the monitor that window is most on. The first that fits on its monitor clear of them all wins; else the one that covers them least, or over origin on the side with more room.
