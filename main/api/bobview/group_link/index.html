Module group_link 

Source
Expand description

Widgets that show the group a vacuum space’s link field names, as the DLS get_pv_name.py script makes them (see bob::GroupLink).

The link field is subscribed with the widget, and the widget is pointed at the group each time the field names a different one: its properties change as the script would set them, so its tooltip, actions and PV menu follow, and its PV becomes the group’s :STA, dropping the one before. The script polls once a second; a link changes rarely, so this does nothing until its value does.
