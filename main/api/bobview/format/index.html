entry_value 🔒
The text to write for what was typed into a text entry, as Phoebus’s FormatOptionHandler.parse makes it: trailing units (anything after the last space) dropped from a number, 0x… and 0b… read as hex and binary, an enum label as its index; the PV’s backend converts the rest. A number that does not parse is written as Phoebus leaves it, without its units; other text as it is.
