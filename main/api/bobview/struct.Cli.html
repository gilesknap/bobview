Expand description

A lean viewer for Phoebus .bob displays (and CS-Studio BOY .opi).

Fields§

§display: Option<String>

display.bob, display.opi or http(s)://host/display.bob

§macros: Option<String>

Macros for the display

§project: Option<PathBuf>

Open a display file through the linked folders of the Eclipse project in DIR (its .project, or for a BOY .opi screen the links of a DLS runcss.sh in DIR), so that links between the project’s modules work

§zoom: Option<f32>

Fixed zoom (0.2 to 5) instead of fit-to-window

§fullscreen: bool

Start full screen

§keypad: bool

No longer supported: text entries take the keyboard

§multi_window: bool

No longer needed: pin mode replaced it

§read_only: bool

Refuse every write to a PV (except loc:// ones, which stay in bobview): controls are disabled and a write action says why it did nothing

§layout: Option<String>

Restore the saved window layout NAME

§no_layout: bool

Don’t restore the default layout

§ui_scale: Option<UiScale>

Size of the toolbar and menus relative to the desktop’s scale (default auto: smaller on a small high-DPI screen; also set by BOBVIEW_UI_SCALE)

§snapshot: Option<PathBuf>

Render to a PNG without a window and exit

§size: Size

Snapshot size in pixels; ‘auto’ starts at the window’s default size and resizes it as a window manager would, on a monitor of 1920x1080 points

§scale_factor: f32

Snapshot as on a screen with this desktop scale, e.g. 2.75 for a phone; –click positions are in pixels

§wait: f64

Time for PVs to connect before a snapshot

§click: Vec<Pos2>

Click here before the snapshot (repeatable)

§right_click: Vec<Pos2>

Right-click here before the snapshot (repeatable)

§settle: f64

Time after the last click before the snapshot
