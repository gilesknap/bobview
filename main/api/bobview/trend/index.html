Module trend 

Source
Expand description

Live trends: PVs plotted against time, in trend windows (opened from a widget’s context menu or a BOY “Graph” button) and the strip chart widget. Each PV keeps the samples it has had since the trend opened; there is no archived history.

One PV’s samples thinned for drawing: in each column of time dt wide (a pixel or less), the first, lowest, highest and last sample, which draw the same as all of them.
