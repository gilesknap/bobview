Serve bobview to browsers.

One process gives a browser everything the web build needs, all from the same origin: the app itself, the .bob files and a PV Web Socket (PVWS) at /pvws/pv that speaks the protocol of https://github.com/ornl-epics/pvws and reaches PVs through bobview’s own CA/PVA layer. Run it anywhere caget works and point a browser at it.
