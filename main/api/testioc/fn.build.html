pub async fn build(
    parts: &[Part],
    ca_port: Option<u16>,
    pva_port: Option<u16>,
) -> CaResult<Ioc>
Expand description

Build the IOC for parts and run its startup actions. ca_port None means EPICS_CA_SERVER_PORT or 5064; pva_port None means the EPICS_PVA(S)_* variables or 5075/5076, Some(p) means TCP p and UDP p+1 (0: both ephemeral). PVA serves from here on; call run() for CA.
