A pure-Rust CA and PVA IOC serving a subset of the epics-containers example-services BL01T beamline PVs.

Modules§

image
A simulated detector image: diagonal fringes drifting across the frame, three gaussian spots on Lissajous paths and a little noise, as 8-bit pixels. Built from precomputed tables so a 1024x1024 frame costs about a millisecond, into a small pool of reused buffers.

Structs§

Ioc
A running IOC: the CA server, and a PVA server that is already serving. Dropping it stops scanning and PVA but not the CA server task.

build
Build the IOC for parts and run its startup actions. ca_port None means EPICS_CA_SERVER_PORT or 5064; pva_port None means the EPICS_PVA(S)_* variables or 5075/5076, Some(p) means TCP p and UDP p+1 (0: both ephemeral). PVA serves from here on; call run() for CA.
