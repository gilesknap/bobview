Rust API

The workspace's crates are documented with rustdoc, built into this book under api/.

Libraries:

  • bob: the display model, .bob and .opi reading, macros and project links
  • pv: PV connections over CA, PVA, PVWS and local sources
  • testioc: the test IOC

Programs, documented with their private items, since that is all they have:

  • bobview: the viewer, its egui app and widgets
  • bobview_server: the web server and its PV Web Socket
  • bobview_probe and bobview_testioc: the command-line front ends of bobview-probe and bobview-testioc

The crates are on crates.io (see Install from crates.io), but their API is not stable; it is documented for contributors.

In a local build the links work when the book is built with scripts/build-docs.sh (see Build from source), not with a plain mdbook serve.
