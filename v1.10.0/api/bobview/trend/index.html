Trend windows: PVs plotted against time, archived history and live values, by archiveview’s [Plot]. Opened from a widget’s context menu, a BOY “Graph” button, or a Data Browser or StripTool launcher. The plot fetches history from the Archiver Appliance bobview was given (--archiver), or is live only without one.

A middle-click on the plot adds the PVs the primary selection names, and one in its search box pastes the selection there: the plot reports the click, BobApp reads the selection (on a thread, see crate::selection::Reader) and hands the text back to Trend::selected.

Constants§

PRIMARY_DEBOUNCE 🔒
Text selected in the search box becomes the primary selection once it has stayed the same this long, as in archiveview: not at every shift+arrow, which over ssh -X costs a round trip each.
SELECTION_WAIT
How long a middle-click waits for the primary selection, as in archiveview: long enough for a slow owner (or ssh -X), short enough that a hung one (arboard waits up to 4 s per format) gets a “Could not read the selection” while the click is still fresh, rather than PVs turning up long after.
