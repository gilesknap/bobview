Module pvws 

Source
Expand description

A PV Web Socket server in the dialect of https://github.com/ornl-epics/pvws.

Clients send subscribe, clear, write, list and echo messages and get one update per changed PV: full metadata first, then only what changed. Like PVWS, an update with neither value nor text means the PV is not connected.
