# Licences

bobview is Apache-2.0.

The release binaries include third-party crates, among them the
[epics-rs](https://github.com/epics-rs/epics-rs) CA and PVA libraries
(EPICS-style open licence), and embed the Liberation Sans fonts and a symbol
subset of Noto Sans Math (both SIL Open Font Licence) and egui's default
fonts. Their notices are in `THIRD_PARTY_LICENSES.txt` in each release
tarball, generated by `scripts/third-party-licenses.py`.

`tests/displays/demo.bob` and the test IOC's `ea.db` come from
epics-containers example-services (Apache-2.0).

These docs draw their diagrams with [Mermaid](https://mermaid.js.org)
(MIT), in `docs/theme/mermaid.min.js`.
